# My Website

A basic placeholder website with three tabs: **Photos**, **Products**, and **Contact**.

This is a starting point — no backend is wired up yet, so the contact form doesn't actually send messages. Swap in real content, images, and a form handler (e.g. Formspree, Netlify Forms, or a custom backend) when ready.

## Structure

- `index.html` — main page markup and tab structure
- `assets/style.css` — styling
- `assets/script.js` — tab switching and contact form placeholder behavior

## Viewing locally

Just open `index.html` in a browser, or serve the folder with any static file server.

## Deploying

This repo is a static site, so it can be hosted for free with **GitHub Pages**:

1. Go to the repo's **Settings → Pages**
2. Under "Build and deployment", set Source to **Deploy from a branch**
3. Pick the `main` branch and `/ (root)` folder, then Save

The site will be live at `https://<username>.github.io/<repo-name>/` within a few minutes.
